# 한국어 설명과 기록

사용자에게 보이는 설명·질문·UI metadata·보고서는 한국어로 쓴다. 코드 식별자·명령·외부 API 이름은 필요한 원문을 유지한다. 결과가 누구에게 무엇을 바꾸는지 먼저 쓰고 근거·검증·제약을 이어 쓴다.

번역투, 추상적인 명사, 똑같은 문장 리듬, 관성적인 칭찬과 과도한 불릿을 줄인다. 뜻·수치·권한·불확실성·출처는 보존한다. 짧게 쓰기 위해 필요한 내용을 삭제하지 않는다. 긴 문장은 주체와 동사가 드러나도록 나누고 병렬 항목은 비교가 쉬울 때만 표나 목록으로 쓴다. AI 문체를 고친다는 이유로 사실을 추가하거나 모든 문장에 임의 금지어 규칙을 적용하지 않는다.

주석은 코드만으로 드러나지 않는 이유·외부 제약·의도적인 예외를 설명할 때 남긴다. 단계 중계, 이름을 반복하는 주석, 오래된 설명을 줄인다. 라이선스·도구 directive·접근성 근거를 임의 삭제하지 않는다. 프로젝트의 실제 지침과 주석 역할을 확인하며, 주석을 일괄 금지하는 개인 전역 규칙으로 확대하지 않는다.
