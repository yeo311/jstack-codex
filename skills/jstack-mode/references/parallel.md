# 일반 Codex 내부 병렬 분업

이 플러그인은 서로 다른 모델을 동시에 호출하지 않는다. 모델 slug·reasoning 예산·외부 모델 API를 설정하지 않고 내부 subagent는 현재 Codex 모델과 환경을 상속한다. 같은 모델의 독립 검토는 관점과 맥락을 분리하지만 다중 모델 다양성과 같다는 보장은 없다.

독립 작업이 실제로 있을 때 내부 Codex 도구의 가용성을 확인해 분업한다. 소스 조사·기능별 읽기·독립 테스트·별도 파일 구현에 유용하다. 짧은 작업은 직접 수행한다. 필요한 수만 시작하고 같은 범위를 반복 조사하는 큰 panel을 만들지 않는다. 도구가 없거나 budget이 부족하면 같은 절차를 순차 수행하고 제한을 기록한다.

brief에는 목표, 읽을 경로, 쓸 수 있는 경로, 금지 경로, 이전 결정, 완료 조건, 검증 명령, 결과 형식을 넣는다. 한 file/branch/worktree에는 한 writer만 둔다. 같은 브라우저·포트·데이터·사용자 세션은 한 사람이 조작한다. 병렬 source readers는 브라우저를 조작하지 않는다. 개인 상태는 helper로 기록하고 child가 보고한 증거는 parent가 직접 확인한다.

작업자는 경로·전체 SHA·실행한 검사·결과·남은 blocker를 반환한다. 결과 통지는 큐 항목으로 다루고 의존 작업에 근거를 전달한다. 대기·재개·중단 도구는 해당 환경이 제공할 때만 사용한다. cloud worker, thread 메시지, worktree 생성 권한이 자동 존재한다고 가정하지 않는다. 외부 메시지는 작업 brief만으로 승인되지 않는다.
