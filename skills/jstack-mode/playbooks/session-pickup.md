# 작업 재개

1. 개인 plans/reports/decisions/program을 읽고 현재 branch/head/git status·프로세스 상태와 대조한다.
2. 원래 brief와 이후 사용자 수정·권한·gates를 새 실행에 전달한다. 오래된 model report를 그대로 믿지 않는다.
3. 마지막 증거가 현재 source/build에 유효한지 확인하고 불확실한 단위만 필요한 만큼 재검증한다.
4. 현재 완료 조건과 다음 unit을 명시하고 실제 요청 범위에서 이어간다. 다른 사용자의 state나 unrelated project를 조회하지 않는다.

[개인 상태](../references/state.md), [프런트엔드](../references/frontend.md), [권한](../references/permissions.md)을 적용한다. 병렬 실행은 [일반 Codex 분업](../references/parallel.md)으로 제한하고 결과·정확 SHA·실행한 검증·남은 blocker를 한국어로 전달한다.
