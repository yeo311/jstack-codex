# 작은 실험

1. 판단할 질문·가설·관찰 기준·시간 범위를 정한다. 실행으로 알 수 있는 사실을 사용자 선호 질문으로 넘기지 않는다.
2. 작은 sketch를 개인 prototype/plan 영역 또는 명시 허용된 제품 경로에 만든다. 회사 코드를 통째로 개인 plugin source로 복사하지 않는다.
3. 실제 interaction·레이아웃·타이밍을 확인한다. 대안이 필요하면 구조가 다른 소수의 안을 같은 모델로 순차 또는 scope 분리해 비교한다.
4. 실험 결과와 제품 선택을 분리해 설명한다. 버릴 sketch를 production 완료로 주장하지 않고 요청된 유지 여부와 cleanup 경계를 기록한다.

[개인 상태](../references/state.md), [프런트엔드](../references/frontend.md), [권한](../references/permissions.md)을 적용한다. 병렬 실행은 [일반 Codex 분업](../references/parallel.md)으로 제한하고 결과·정확 SHA·실행한 검증·남은 blocker를 한국어로 전달한다.
