# 한국어 문체 정리

1. 현재 글의 의미·숫자·조건·권한·불확실성을 먼저 보존한다.
2. 기계적 병렬·번역투·추상 명사·접속사 반복·불필요한 영어 인용을 자연스러운 한국어 문장으로 바꾼다.
3. 관성적 praise·상투적 결론·과한 emoji/불릿을 줄인다. 짧은 글이라도 필요한 근거와 한계를 삭제하지 않는다.
4. 수정 전후의 사실과 조건이 같은지 확인한다. 영어용 금지어를 한국어에 기계적으로 옮기지 않는다.

## 공통 경계

[개인 상태](../jstack-mode/references/state.md)와 [프런트엔드](../jstack-mode/references/frontend.md), [권한](../jstack-mode/references/permissions.md)을 따른다. 분업이 필요할 때만 [일반 Codex 병렬 기준](../jstack-mode/references/parallel.md)을 읽는다. 설명은 [한국어 문체](../jstack-mode/references/writing.md)를 따른다.

## 결과

의미와 수치·조건·불확실성을 보존한 자연스러운 한국어 본문.
