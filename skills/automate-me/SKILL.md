# 개인 작업 방식 반영

1. 현재 요청과 직접 관련된 반복 선호·수정 이력만 확인한다. 사용자 전체 대화나 회사 문서를 기본 수집하지 않는다.
2. 관찰된 선호와 추측을 구분하고 기존 지침과 충돌하는 선택을 사용자에게 확인한다.
3. 개인 verification 또는 plans 영역에 스킬 초안을 작성한다. 실제 personal skill 설치·기존 plugin 변경은 사용자가 요청한 범위에서만 수행한다.
4. 스킬이 달라지게 만드는 비일반적 규칙만 남기고 한국어 문체를 다듬는다. 서로 다른 예제에서 행동을 확인하고 효과와 한계를 기록한다.

## 상세 기준

[기존 mode의 범위를 보존하며 갱신·반복 근거·좁은 trigger·사용자 calibration을 적용한다.](references/personal-mode.md)

## 공통 경계

[개인 상태](../jstack-mode/references/state.md)와 [프런트엔드](../jstack-mode/references/frontend.md), [권한](../jstack-mode/references/permissions.md)을 따른다. 분업이 필요할 때만 [일반 Codex 병렬 기준](../jstack-mode/references/parallel.md)을 읽는다. 설명은 [한국어 문체](../jstack-mode/references/writing.md)를 따른다.

## 결과

확인한 개인 선호와 근거, 한국어 스킬 초안, 충돌하는 선택과 검증 예제, 설치·수정 권한 범위.
